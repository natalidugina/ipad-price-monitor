# iPad Price Monitor

Система мониторинга цен и наличия Apple iPad Air M3 11" 256 GB
в нескольких интернет-магазинах.

## Задача

Автоматизировать сбор цен и наличия товара, чтобы не проверять
каждый магазин вручную и выбрать наиболее выгодный момент покупки.

## Демонстрация

Результаты мониторинга доступны в Google Sheets:

[Открыть демонстрационную таблицу](https://docs.google.com/spreadsheets/d/1hj-U3KHiE5pyIkW1xhzTWCNfFb6rTiD-1tDAg20j5yQ/edit?usp=sharing)

## Что делает проект

- проверяет цены и наличие в нескольких магазинах;
- обрабатывает динамические страницы через Playwright;
- автоматически выбирает Санкт-Петербург в Unit Store;
- различает статусы:
  - товар в наличии;
  - товар отсутствует;
  - данные получить не удалось;
- отправляет результаты в Google Apps Script;
- сохраняет одну общую строку в Google Sheets.

## Обработка ошибок

Проект не записывает случайную цену, если сайт изменил структуру
или загрузился не полностью.

В таблицу записываются:

- числовая цена;
- `Нет в наличии`;
- `Не удалось получить`.

## Запуск

### 1. Подготовка окружения

Создайте файл `.env` на основе `.env.example` и заполните:

```env
APPS_SCRIPT_URL=your_apps_script_web_app_url
API_TOKEN=your_secret_token
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Ручной запуск в Windows

Дважды запустите файл:

```text
run_price_monitor.bat
```

Он:

- проверяет, запущен ли Chrome на порту `9222`;
- при необходимости запускает специальный профиль Chrome;
- запускает мониторинг;
- оставляет окно консоли открытым, чтобы можно было увидеть результат.

## Особенности запуска в Windows

BAT-файлы ищут Google Chrome по стандартному пути:

```text
C:\Program Files\Google\Chrome\Application\chrome.exe
```

Если Chrome установлен в другом месте, путь в файлах:

- `run_price_monitor.bat`;

нужно заменить на фактический путь к `chrome.exe`.

Путь к папке проекта не зашит в BAT-файлы. Команда:

```bat
cd /d "%~dp0"
```

автоматически переключает рабочую папку на каталог, в котором находится сам BAT-файл.

Виртуальное окружение ожидается в папке:

```text
.venv
```

Если используется другое имя виртуального окружения или системный Python, команду запуска Python в BAT-файлах необходимо изменить.

## Ограничения

- Запуск мониторинга выполняется вручную через run_price_monitor.bat.
- Для DNS и Unit Store используется отдельный профиль Google Chrome.
- Структура сайтов может измениться, поэтому селекторы периодически могут требовать обновления.
- Автоматический запуск по расписанию рассматривается как следующий этап развития проекта.
